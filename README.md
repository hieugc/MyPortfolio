# MyPortfolio

Version 2 of Pham Minh Hieu's personal portfolio / CV website.

## Highlights
- Professional engineering-focused visual direction
- Responsive desktop/mobile layout
- English / Vietnamese toggle
- Project case-study presentation
- Export CV menu
- Existing CV PDF link preserved
- Print / Save as PDF support
- Copy profile summary action
- No build step required

## Local preview
Open `index.html` directly in a browser, or serve this folder with any static server.

## Deployment
This repository is suitable for GitHub Pages.

## Source
Content is based on the existing `mycv` portfolio data and CV content.
